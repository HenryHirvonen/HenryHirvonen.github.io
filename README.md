# Henry Hirvonen — Research portfolio

A lightweight, single-repository static portfolio for GitHub Pages. No build tools or large data uploads needed.

## Publish using GitHub's website
1. Create a public repository named `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your GitHub username).
2. Choose **Add file > Upload files** and upload `index.html` and `style.css` from this folder (not the ZIP). Commit the changes.
3. Go to **Settings > Pages**, select **Deploy from a branch**, `main`, and `/ (root)`. Save.
4. Visit `https://YOUR-USERNAME.github.io` after deployment completes.

## Before sharing
- Replace the generic Zenodo link with the exact DOI/record URL.
- Add your LinkedIn and email links in the Contact section.
- Check all descriptions against your papers and your personal contributions.
- Add real research figures only when their reuse is permitted.
- The FNO and Kokkos work is described conservatively because it is collaborative/ongoing.
- You can edit text directly in `index.html` using GitHub's browser editor.

Large data, model weights, and archival research code can stay on Zenodo.
