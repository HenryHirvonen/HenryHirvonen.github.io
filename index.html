01 / DEEP LEARNING · SURROGATE MODELS

Neural-network surrogate for faster simulation

Developed and trained a DenseNet-based surrogate to reduce the cost of numerical model evaluations. Achieved approximately 5,000× faster inference and validated predictions against 90,000 independent simulation events, including tests with different initial conditions.

02 / PROBABILISTIC MODELING

Machine learning for Bayesian parameter inference

Trained parameter-conditioned neural-network surrogates and generated simulation datasets for Gaussian-process emulators. This supported inference across 15 physical parameters. I also contributed to interpreting the resulting constraints and testing their sensitivity to added theoretical uncertainty.

Bayesian inference Gaussian processes UQ

03 / NUMERICAL SOFTWARE · HPC

Numerical solver development with C++ and Kokkos

Co-developed a relativistic hydrodynamics solver for CPU and GPU architectures. My contributions included finite-volume implementation, equation-of-state functionality, and numerical verification using convergence tests and semi-analytical solutions. The work is described in our 2026 BDNK preprint.
